# Sparks Gifts – Admin / CMS Guide
Login: /admin/login

| Admin menu | What you can change |
|---|---|
| Dashboard | Sales, orders, profit overview |
| Products | Add/edit/delete, images, price, cost, stock, SKU, sold out |
| Categories | Add/edit/delete, images |
| Orders | View and change status |
| Custom Requests | On-demand requests + online payment status |
| Customers | List of everyone who ordered (WhatsApp link) |
| Website Content | ALL text: hero, features, how-it-works, testimonials, About, Contact, FAQ, policy pages, announcement bar, footer, SEO |
| Settings | Store name, phone, email, WhatsApp, social links, delivery & wrapping charges, online payment accounts |
| My Account | Change admin email / name / password |

No SQL is needed for the CMS (content is saved in the existing store_settings table).
Only drizzle/0003_custom_request_payment.sql must be run once.
